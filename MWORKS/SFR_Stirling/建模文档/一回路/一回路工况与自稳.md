## 1 无 PID 自稳验证（2026-09-06）

### 1.1 对象与改动

对象：`Structure.PrimaryLoop.v1_fixed`（一回路独立模型，文件夹式包）。相对带 PID 版本的改动：

| 项 | 原模型 | 无 PID 版 |
|---|---|---|
| 控制棒反应性 | PID(NoInit)→LimPID→`Reactivity_CR` | `constCR(k=0)` 恒 0（PID 旁路保留在图上） |
| 燃料反馈 | 常数 823.15（实际断开） | $0.2237T_{wall}[6]+0.7763T_{wall}[6]$ 份额加权 |
| $T_{effref,fuel}$ | 864.05（TubeWall 时代残余） | 863.2 K（旧模型稳态外推） |
| $T_{effref,coolant}$ | 767.18（残余） | 768.29 K（$dT/dQ$=1.64 K/MW 外推） |
| 初始热态 | 冷芯堆（注释 440 ℃ 实为 425.6 ℃）→$\rho_0\approx+1100$ pcm | 活性段 $h_{start}$=607863（$T[6]$ 初值=额定 767.18 K，$\rho_0\approx0$） |
| 初始功率 | $Q_{fission}$ 固定 40 MW | `Q0_start` 参数（A=40e6 定值 / B=44e6 扰动） |

### 1.2 工况 A：定值自稳（40 MW，300 s）

| t / s | Q / MW | $\rho_{total}$ | 备注 |
|---|---|---|---|
| 0 | 40.000 | ≈0 | 额定热态启动 |
| ~50 | 40.43 | −9.9e-5 | 微小扰动过冲 |
| 200 | 40.005 | −5.9e-6 | 反馈拉回 |
| **300** | **40.004** | −7.1e-7 | **自稳 ✓（+0.01%）** |

终态：堆芯入口 440.04 ℃、出口 550.05 ℃、二回路出 HE1 530.09 ℃、$T_{eff,fuel}$=864.05 K、$T_{eff,coolant}$=768.29 K。

### 1.3 工况 B：+10% 功率扰动回归（$Q_0$=44 MW，300 s）

| t / s | Q / MW | 说明 |
|---|---|---|
| 0 | 44.000 | +10% 扰动注入 |
| 0.05 | 36.05 | 燃料反馈即时压降 |
| 0.2 | 24.02 | 瞬发压低 |
| 1~10 | 48.8 | **过冲峰值 ≈48.8 MW（+22%）**，缓发中子+冷却剂滞后 |
| 50 | 42.62 | 回落 |
| 100 | 40.43 | 收敛中 |
| **300** | **40.004** | **回归额定 ✓（+0.01%）** |

### 1.4 结论与边界

1. **可以**：在额定平衡点邻域，无 PID 点堆能自稳于 40 MW，且 +10% 扰动可自行恢复（负反馈：燃料/冷却剂温度）；
2. 恢复时间由热惯性决定（~100–200 s 收敛到 ±0.1%）；瞬态峰值幅度由燃料反馈强度与冷却剂滞后决定；
3. **冷态（欠额定热态）无棒不能自稳**——默认初值（堆芯 425.6/506.8 ℃、壁温 298 K）在无 PID 时 $\rho_0\approx+1100$ pcm，超瞬发临界，功率毫秒级发散；自稳性只在额定平衡点邻域成立（物理正确：启动需控制棒）；
4. 燃料反馈用**通道壁温**（棒体平均口径的代数近似，非燃料中心温度），多普勒反馈的瞬时性偏理想；更真实需径向 2~3 节点管壁组件。

## 3 70% 流量固定热阱响应（`PrimaryLoop/v2_flowDown`）

场景：一、二回路流量同步 −30%（280.6→196.42 / 308.4→215.88 kg/s），CR≡0，3600 s；二回路以固定 430 ℃ 恒温入口边界 + 同步流量近似。

| 量 | 额定段（t<1200 s） | 终态 | 变化 |
|---|---|---|---|
| 核功率 | 40.004 MW | **29.515 MW** | **−26.2%** |
| 堆芯热/冷段 | 550.0 / 440.0 ℃ | 553.0 / 437.0 ℃ | ΔT=116.0 K |
| 二回路出/入 | 530.0 / 430.0 ℃ | 535.5 / 430.0 ℃ | ΔT₂=105.5 K |
| 燃料壁温 $T_{eff,fuel}$ | 864.0 K | 851.0 K（−13.0 K） | — |
| 终态反应性 | — | $\rho_{fuel}$=+35.6 pcm、$\rho_{cool}$=−35.6 pcm、总≈0 | — |

能量闭合：215.88×1296×(535.5−430)=**29.52 MW**=堆芯功率 ✓；196.42×1296×116.0=29.52 ✓。

**结论**：固定恒温入口热阱下，流量 −30% → 排热能力 ∝ 流量 → 功率被压至 29.5 MW（−26.2%），平台 ±3 K，属“功率随排热能力下降”的固有安全行为。含斯特林系统的对照见 `二回路/二回路工况_排热下降与流量70%.md`（同场景下功率不降反升 +8.3%，与尹凯论文同族）。

## 4 使用边界

1. 无 PID 自稳结论**只适用于额定平衡点邻域**；启动/大范围变工况需控制棒或 PID；
2. 反馈参考 885.5/768.28511 K 按额定点标定，跨工况存在零点漂移（燃料反馈 $\Delta T_{wall}$ 96→122 K 会把平衡推向更高功率）；
3. 燃料反馈是集总壁温口径，不能直接与“燃料热点温度”比较；
4. 旧记录（863.2/768.29、heff 1.41、d 10.6）不得与新参数混用。
