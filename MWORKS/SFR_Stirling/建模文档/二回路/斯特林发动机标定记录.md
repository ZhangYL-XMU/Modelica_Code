| 指标 | 目标 |
|---|---|
| 钠侧进/出口 | 530 → 430 ℃（$m c_p\Delta T\approx40$ MW，40 组口径） |

## 2 v3 双回路台架（2026-09-07）

### 2.1 台架结构

- 钠侧：308.4 kg/s 经引擎加热器管束（`Engine_pipe`：3200 根 Φ4 mm × 0.5 m，$n_{pipe}=3200$、$D_h=0.004$、`CF_HeatTransfer=6`）；引擎吸热 `Q_in` 经 `prescribedHeatFlow`（4 节 × Q_in/4）从管壁取热；
- 水侧：200 kg/s 经冷却器管束（`water`：70000 根 Φ1 mm × 0.12 m，$n_{pipe}=70000$、$D_h=0.001$、`CF_HeatTransfer=1`）；引擎排热 `Q_out` 经 `prescribedHeatFlow1`（4 节 × Q_out/4）注入水壁；
- 引擎温度输入：`T_Na` = `Engine_pipe.T[1..4]` 流体温平均；`T_water` = `water.T[1..4]` 流体温平均；
- 钠入口 h=656857（ramp offset 654480）→ 803.15 K（530.00 ℃）；出口背压 h=527257（430 ℃）；
- 初始化：两侧 `initFromEnthalpy=false` 温度初始化（803.15/311.15 K），与边界一致。

### 2.2 标定值（v3）

| 参数 | 值 | 说明 |
|---|---|---|
| `U_h` | **2.0e4 W/K** | 加热器换热（辅助标定） |
| `U_c` | **4.5e5 W/K** | 冷却器换热（论文推测 3.0e4 → 标定抬高） |
| `U_reg` | **3.0e6 W/K** | 回热器（论文推测 1.0e5 → 标定抬高） |
| `heff_Na` | **1.53** | 主标定量：桥接物理吸热（≈26.4 MW/40 组）与钠侧 40 MW |
| `heff_water` | 1.0 | 保持 |
| `damper.d` | **10.30** | 台架负载（转速标定，优先级最低） |

### 2.3 验证结果（20 s 仿真，t=19~20 s 均值）

| 指标 | 实测 | 目标 | 偏差 |
|---|---|---|---|
| $Q_{in}$（40 组） | 40.13 MW（单组 1003.2 kW） | 40.0 MW | +0.3% ✓ |
| 钠入口 | 530.00 ℃ | 530 ℃ | 精确 ✓ |
| 钠出口 | 429.60 ℃ | 430 ℃ | −0.4 K ✓ |
| 单组功率 | 245.25 kW | 250 kW | −1.9% ✓ |
| 热效率 | 24.45% | 25% | −0.55 pp ✓ |
| 转速 | 1506.6 rpm | 1500 rpm | +0.44% ✓ |

能量闭合：$Q_{in}=308.4\times1296\times100.55\ \text{K}=40.13$ MW；$Q_{in}\approx Q_{out}+power\times40$（40.13≈14.58+9.81 MW）✓。

### 2.4 关键决策与过程记录

1. **温度取样口径**（用户修正）：`T_Na` 取加热管束**流体温**（`Engine_pipe.T`），不是壁温 `T_wall`；水侧同样取流体温；关注参数为钠进出口温度（530→430 ℃）。
2. **代数壁温失稳**：`pipe` 的 `wall.T` 为零热容代数节点，水侧壁温反馈形成正反馈代数环（稳定条件 $\gamma A_w>40U_c$）；CF 小则初始化失稳、CF=200 运行期刚性卡死（t≈20.7 s）。故水侧取流体温；钠侧壁温天然负反馈稳定，但按同一口径取流体温。
3. **530 ℃ 入口修正**：钠 $h(T)=2377+1296(T-298.15)$；$h=631755$ 实为 510.6 ℃，530 ℃ 对应 $h=656857$（cp 增量 654480 由 ramp offset 提供）。v2 台架入口实为 510.6 ℃，v3 已修正。
4. **heff 作用机制**：`heff_Na` 缩放 `gain k=4×10×heff_Na`（Q_in 端口口径），即钠侧放热 $=heff_Na\times40\times$ 引擎物理吸热。物理功率/转速由 $U$ 与 $d$ 保证。
5. **U 敏感性**：$U_h$/$U_c$/$U_{reg}$ 在高值段均不敏感（2e4→2.4e4、4e5→4.5e5、2e6→3e6 功率变化 <3%）；功率-转速主要由 $d$ 与引擎特性决定（$d\omega^2$ 守恒）。
6. **仿真时长**：该台架约 20 s 达稳态，后续直接 20 s 仿真取 19~20 s 均值。

## 4 历史记录：v2 单侧台架（2026-08-30，已被 v3 取代）

- 对象：`DA_Engine_v2`，台架 `Test_Engine_v2`（钠 530 ℃ 恒定边界 + 飞轮 + damper；`T_water=323.15 K` 引擎内常数）。
- 标定原则：除换热系数外全按论文/设计；唯一标定量 = $U_h$/$U_c$/$U_{reg}$ 集总换热。
- 结果：$U_h=2.0e4$、$U_c=2.0e5$、$U_{reg}=1.0e6$ W/K、$d=10.14$ → **250.5 kW / 1508 rpm / $Q_{in}$ 712.8 kW / η 35.1%**（目标 250/1500/746/33.5%）。
- 迭代：基线（原换热 + $P_m$ 18.7 MPa、d=15）181 kW/1085 rpm → 关损失+强换热+20 MPa 305 kW/1376 rpm → $P_m$=13.5 MPa+d=10.14 216 kW/1455 rpm → $n_{reg}$ 30、$U_h$ 1e4 240.5 kW/1482 rpm → d=9.5、$U_h$ 1.2e4 249.9 kW/1591 rpm → 恢复全部损失+论文参数，仅 $U_h$ 2e4/$U_c$ 2e5/$U_{reg}$ 1e6 + d=10.14 → 250.5 kW/1508 rpm。
- v3 相对 v2 的修正：① 钠入口由 $h$=631755（实为 510.6 ℃）改为精确 530 ℃；② 冷端由固定 323.15 K 改为水回路动态耦合；③ 增加 40 组口径钠放热约束（530→430 ℃，$Q_{in}$=40 MW）；④ 台架几何按论文表 7。

## 6 复现要点

1. 台架模型：`SFR_Striling.Stirling.DoubleActing.Test.Test_Engine_v3`；
2. 仿真：Dassl、0~20 s、Tolerance 1e-4，取 19~20 s 密集均值；
3. 参数按 §5 最后一列（Base.mo 定稿）；
4. 判据：$Q_{in}$ 40.0 MW（40 组）、钠 530→430 ℃、单组 250 kW、1500 rpm；
5. 若改 $U_h$：会同时影响引擎物理吸热与 heff 桥接口径，须重标 $heff_{Na}$；
6. 若改 $d$：转速按 $d\omega^2$ 守恒移动，功率随之小幅变化。
