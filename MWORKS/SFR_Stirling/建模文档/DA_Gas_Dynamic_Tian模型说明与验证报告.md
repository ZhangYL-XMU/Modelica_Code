## 2 理论基础（田文静论文公式映射）

模型完全以田文静《斯特林发动机热力循环计算及性能模拟》（兰州理工大学硕士论文，2011）为理论依据。按论文 **2.2.3 节节点分析法**把每循环工作区划分为控制体：**热侧（热腔+加热器）1 节点 / 回热器 5~20 节点（论文原文"回热器分了5个控制体"，且"越多越好"，默认取 20）/ 冷侧（冷腔+冷却器）1 节点**，4 缸双作用构成 4 个闭式循环。

### 2.1 公式映射表

| 田论文公式 | 模型实现 |
|---|---|
| 式3-1 开口系能量方程 $dQ+(c_pT_i m_i'-c_pT_o m_o')=dW+c_v\,d(mT)$ | 各 CV 能量方程的时间导数形式（热/冷侧含式3-15 体积功 $p\dot V$，回热器节点定容 $dW=0$） |
| 式3-2 状态方程 $pV=mRT$ | 每个 CV 一个；微分方程中显式代入 $T=pV/(mR)$、$\rho=m/V$ |
| 式3-4 质量守恒 | 每循环闭式：$\dot m_h=-\dot m_{p,h}$，$\dot m_{reg,k}=\dot m_{p,k}-\dot m_{p,k+1}$，$\dot m_c=\dot m_{p,c}$ |
| 式3-14 后 迎风规则（$m'_{ck}>0$ 则 $T_{ck}=T_c$ 否则 $T_{ck}=T_k$ 等） | 交界面焓流温度 = 流出侧 CV 温度，tanh 连续化 |
| 式3-15 做功 $dW=p\,dV$、$\eta=W/Q_h$ | $P_{ind}=\sum_i f_i v_i$；$f_i=(p_{c,i-1}-p_{h,i})A$；$\eta=P_{ind}/Q_{in}$ |
| 式3-16 穿梭损失 $Q_{sh}=K_g\pi D_c S_D(T_h-T_k)/(4f\,\delta)$ | 功率形式 $\dot Q_{sh}=K_g\pi D S(T_{wh}-T_{wk})/(2\delta)$；$K_g=\exp(A+B\ln T_r)$ [W/(cm·K)] 换算 |
| 式3-17~3-20 流动摩擦阻力 $F=\tau A_{wg}=2C_f\rho u^2V/d$、$F+\Delta p A=0$ | 压降-流量关系的基础 |
| 式3-21 压降 $\Delta p=-2\,Cref\,\mu\,u\,V/(d^2A)$，$Cref=Re\,C_f$，$Re=\rho ud/\mu$ | 反解出界面质量流 $\dot m=(p_{up}-p_{down})/R$，$R=2\,Cref\,\mu\,V/(d^2A^2\rho)$；三个换热器压降串联，回热器链各节点分摊 |
| 式3-22~3-24 Cref(Re)：16 / $7.343\times10^{-4}Re^{1.3142}$ / $0.0791\,Re^{0.75}$ | CrefSmooth 函数（过渡带连续化，段内与论文完全一致） |
| 式3-21 后 $\mu=[88.73+0.200(T_r-293)+0.118\,p_m]\times10^{-7}$（氢气） | 同一线性形式，系数按工质物性给出：氦气 A=196.0/B=0.435/C=0（300K/500K 两点拟合）；田复现用氢气原文系数 |
| 式3-18 后 水力直径 $d=4V/A_{wg}$ | 回热器丝网 $d_{rx}=$丝径×孔隙率/(1−孔隙率) |
| 式3-25 压降损失 $W_{\Delta p}=(\omega/2\pi)\oint \Delta p\,dV_c$ | 诊断量 $N_p=\sum R\dot m^2$（流阻耗散功率，与之等价） |
| 式3-28 回热器换热 $\dot Q=c_p\dot m(T_{h1}-T_{h2})=2hA_{wg}\Delta T$ | 逐节点 $Q_{reg,k}=(U_{reg}/n)(T_{mat,k}-T_{reg,k})$，$U_{reg}=2hA_{wg}$ |
| 式3-30/3-31 $NTU\equiv hA_{wg}/(c_p\dot m)$，$\varepsilon=NTU/(1+NTU)$ | 诊断输出回热效率 |
| 3.1.1 节 回热器有效温度 $T_r=(T_h-T_k)/\ln(T_h/T_k)$ | 物性（μ、$K_g$）参考温度 |
| 3.2.4.2 节+图3.6 回热器中温度成线性变化 | 各节点网阵锚定到线性剖面 $T_{lin,k}=T_{he}-(k-0.5)(T_{he}-T_w)/n$，时间常数 $\tau_r=1$ s |
| 式4-4 对流换热 $Q=hA_{wg}(T_w-T_g)$ | $Q_h=U_h(T_{na}-T_h)$、$Q_c=U_c(T_w-T_c)$ |

| 4.1.2 节 初始条件（热侧=热壁温、冷侧=冷壁温、回热器=对数平均） | 初值设定 |

### 2.2 数值实现说明（不改变物理结论）

1. **显式消元消除代数环**：能量方程中 $T=pV/(mR)$、$\rho=m/V$ 直接符号代入，消除"$\dot p$ 依赖 $T$、$T$ 依赖 $p$"的代数环（编译器本应完成的等价变换），Dassl/Ida/Rkfix4 均兼容，后续接入钠冷快堆整机用 Dassl 求解时环更少更稳；
2. **一阶低通滤波断环**：Cref 与迎风权重用低通流量（$\tau=1\times10^{-4}$ s，为周期 0.25%）评估，断开 Cref–Re 自指环；
3. **回热器线性剖面锚定**：3.2.4.2 节"温度成线性变化"假设的集总实现，网阵温度向剖面位置温度松弛（$\tau_r=1$ s）；
4. **稳态初值**：`initial equation` 中网阵初值直接取线性剖面，与锚定目标自洽，消除启动爬坡瞬态。

## 5 使用方法（16 缸扩展与钠冷快堆接入）

1. **接入 DA_Cylinder**（单组 4 缸，即 DA_Demo 的接法）：4 个 `SFR.Stirling.DoubleActing.DA_Cylinder`（曲柄相位 {0,−π/2,−π,−3π/2}）曲轴串联 + 飞轮/负载，`f_mt = −gas.f[i]`、`gas.s[i] = cyl_i.s_out`（速度内部自动求导）；
2. **扩展为 16 缸（1 MW 整机）**：侯斌 V16-45° = 4 组本模型；4 个 `DA_Gas_Dynamic_Tian` 实例各自接 4 缸（组间曲柄相位错开 45°），热源/冷源并联同接钠温/水温；
3. **接入钠冷快堆**：`gas.T_na` 接二回路钠温（本课题 SFR 模型输出），`gas.T_water` 接淡水系统温度；模型为纯代数+微分 DAE，可直接与堆/回路模型共网求解（建议 Dassl）；
4. **可调关键参数**：`U_h/U_c/U_reg`（换热能力）、`n_reg`（回热器节点数，5=快而粗、20=准，田 2.2.3 节依据）、`P_m`（充气压力，峰值≤20 MPa）、`m_upw/tau_delay/tau_r`（数值参数，一般不动）。

## 6 已知局限（如实说明）

1. **回热器节点离散**：n 节点链的端点温差 ≈ (T_he−T_w)/(2n)，等效 ε 按式3-27 估算；n=20 时 ≈0.95，接近论文 4.4 节的 0.98；n=5 时仅 0.83（田 2.2.3 节的折中值，效率会明显偏低）；
2. **换热能力标定**：侯斌未给换热系数，U_h/U_c/U_reg 按设计点热平衡（式4-4/4-5/3-28）标定，用户可按实际换热关联式替换；
3. **Th≈772 K 略高于表6 的 400 ℃**：因 U_h=7.7e3 对应 Q_h=1 MW/循环的标定假设；实际单循环吸热 250 kW，若需 Th=673 K 可将 U_h 调至约 2e3（式4-5 反算）；
4. **田复现的有限换热工况**：田机加热器 h·A≈300 W/K 时 Th≈947 K（式4-5 的气体温差修正自动体现）；TianCheck 名义实例用 U_h=U_c=1e4 近似等温换热器以对齐表2 框架，两者均已在注释中说明；
5. 压降损失诊断 N_p 与指示功率的差值分配中，回热器总流阻按热端节点密度评估，链内密度修正为近似处理。
