# 摘要

本项目的目标是利用 Dymola 软件对斯特林发动机进行研究、设计、仿真与优化。该软件提供了大量工作选项：设计、模型实现、开发、验证、校核，以及图形、数值和动态等多种仿真，此外还有许多其他功能。本项目旨在让对斯特林发动机感兴趣的人能够全面了解这种发动机是什么以及涵盖哪些内容，此外还可将其用作初步设计或可靠实用的信息来源，以便在实际的现实世界中将其实现出来。

本研究并非从零开始，因为它承接了两个前期项目，是它们的延续，即第三部分。在第一部分中，得到了一个半功能化的斯特林发动机模型。在第二部分中，对该第一个模型进行了改进，得到了一个功能模型，但该模型无法移植到现实世界——尽管在定义范围内它是功能正常的，然而由于其特性有限，无法用于任何实际应用。当前第三部分的目标是继续得到一个对某些实际应用而言功能正常且有用的模型。这将通过开展参数化研究来实现，该研究将在各个层面改进 Dymola 的工作区域、发动机的基本特性以及热力循环，此外还将开展必要的仿真，以获得最终的最优模型。

# 摘要

本项目的目标是使用 Dymola 软件对斯特林发动机进行研究、设计、仿真与优化。该软件提供了无限的工作可能性：设计、模型的实现、开发、校准、校验，以及对所有元件的图形、数值和动态仿真，此外还具备许多其他功能。本项目构想的目的是，让对斯特林发动机感兴趣的人能够对该发动机所包含的一切内容形成概念，并且可以将本项目用作草稿或可靠且实用的来源，从而将这种发动机变为现实。

# 第1章 前言

## 1.1. 项目起源

本毕业设计项目源于近年来围绕斯特林发动机的开发和改进而产生的主观能动性与兴趣。这一点与 EUETIB 流体力学系 (MF) 中对于流热系统仿真的兴趣相结合，从而促成了本项目的开展。

尽管如此，本项目耗时漫长且工作繁重，仿真软件 Dymola 也同样复杂且具有众多可能性。因此，从一开始便决定将项目划分为多个部分，本部分为第三部分。这样一来，可以对每一部分进行更深入的研究，将其做得更好，从而获得最佳且称职的最终成果。

## 1.2. 动机

作为一名能源工程专业的学生，同时也作为一名关注环境、效率以及能源和经济节约的人，我从一开始就被这个项目所吸引，因为斯特林发动机可以利用太阳能来运行，太阳能是一种免费的能源，潜力巨大且几乎无排放，因此可以获得良好的效率。此外，这种类型的发动机具有非常高的效率，如果能够以高效且称职的方式开发出来，未来在许多应用中都将大有可为。

另一方面，在本能源工程学士学位的学习过程中，我修读了多门仿真课程，这些课程让我觉得非常有趣，因为显而易见，仿真就是未来，它可以应用于无数不同的领域，能够获得与真实情况非常相似、因而可靠的结果，并且由于仿真可以节省大量本需实际执行的测试或验证工作，从而带来十分可观的经济节约。

# 第2章 项目目标

在本节中，我们将目标分为两组：总体目标，它涉及整个项目；以及具体目标，它们更具体地针对这第三部分。

## 2.1. 总体目标

本毕业设计项目的总体目标是,借助 Dymola 软件及其整个工作与仿真环境,获得一个完全功能化、切实可行且性能优异的斯特林发动机模型。我们从一个功能正常但有所局限、既不可行也不优异的模型出发,通过对它的研究与优化,最终达到所期望的总体目标。

## 2.2. 具体目标

在本项目的整个实施过程中,我们确立了若干具体目标,它们共同服务于达成最终目标:

• 认识并学会在设计、编程与仿真环境中使用 Dymola 软件。

• 深入研究、分析并透彻理解斯特林发动机及其热力循环在机械与热力学两方面的运行原理。

• 分析项目此前的状态,透彻理解它,寻找并落实如何继续推进并改进它。

将 Dymola 中的所有编程与工作环境参数化,以获得更加协调的行为,使其作用于程序的各个层面,并便于对程序与项目的解读和使用。

• 完成所需的仿真研究,并对结果进行详尽的分析。

• 得到一个性能更好、转速更高且发电功率有所提升的发动机原型。

# 第3章 绪论

我们将斯特林机定义为这样一种装置:它通过再生的热力循环,将热量转换为功,或反之,伴随着工作流体的周期性压缩与膨胀;该流体在热源与冷源两个温度之间工作。

当机器以容积式方式运行时,称为斯特林机;而当它以持续稳定的流动方式运行时,则称为爱立信机(Ericsson)。

在历史上它们曾有不同的名称,最初被称为热空气发动机,因为当时只使用空气作为工作流体。后来,随着使用其他气体作为流体,它们被称为热气发动机。最终,为纪念其创造者罗伯特·斯特林(Robert Stirling),这一名称被确定为斯特林发动机。

斯特林发动机随着时间的推移不断得到完善。在蒸汽机鼎盛时期,斯特林发动机被大量用于抽水以及其他功率较小的应用,例如风扇,因为它们比蒸汽机安全得多——蒸汽机常因高压而爆炸,而这些发动机以常压空气工作。这一状况一直持续到内燃机的巨大发展,随后电动机的出现使斯特林发动机逐渐被取代。尽管如此,自二十世纪起,人们对斯特林发动机在新应用领域的兴趣重新兴起。制冷、供暖以及利用替代高品质化石燃料的替代热源进行发电,是斯特林发动机相对于其他系统能够具有竞争力的新领域。众多企业、个人和高校院系正致力于设计与实验项目,以研制出足以与现有解决方案竞争的、足够高效的斯特林机器。

目前已有多个样机制成,但在市场上能找到的应用仍然很少。其主要应用是利用太阳能聚光器进行发电,因为这类发动机在将太阳能转换为电能方面具有最高的效率。

![](images/667a6a2a92bccfce07806466055037ed34a5350081c773b3e3cb2545e9ce51cf.jpg)  
图 1:"Dish-Stirling",带斯特林发动机的圆柱-抛物面聚光器

此外,它们还被用作潜艇发动机,因为它们非常安静,并且能够在深水处为电池充电。同样,也存在一种专为游艇设计的斯特林发动机。其他一些应用包括作为热电联产装置(既发电又提供冷却用水),或者直接作为制冷机。

# 第5章 斯特林发动机

斯特林发动机的说明可分为四个明显不同的部分：描述、配置、斯特林热力循环以及功能。

## 5.1. 描述

### 5.1.1. 总体描述

斯特林发动机的创造者罗伯特·斯特林（Robert Stirling）于1816年发明并申请了以他名字命名的发动机专利。他是一位苏格兰神职人员，认为蒸汽机可以改进，正是源于这一想法诞生了斯特林发动机。

它是一种外燃式发动机，与驱动车辆的传统汽油或柴油内燃机相对。该发动机利用外部热源工作，例如太阳能或核能。在将热量转化为功的过程中，斯特林发动机实现了高于现实世界中任何其他发动机的效率，尽可能接近理想的卡诺效率。在实践中它受到限制，因为它不以理想气体工作，且各运动部件之间的摩擦不可避免。

斯特林发动机利用固定的热源来加热气缸内的空气。它可以被视为外燃式且绝热过程，因为它不需要在内部燃烧燃料，且在运行时不会向环境传递热量。斯特林发动机的核心机构由两个活塞/气缸组成，一个用于散热并将热空气推向冷区，反之亦然。

斯特林发动机由两个活塞（功率活塞和置换器）、一个或两个气缸（视配置而定）、曲轴以及回热器组成。不同的配置在其相应的章节中有说明。

关于回热器，它充当一个在每个循环中储存能量的系统。当气体从热端向冷端移动且温度降低时，热量沉积在回热器中。当气体从冷端向热端移动时，回热器向气体供给能量，使其温度升高。

回热器或称省热器是为提高机器的效率而开发的。该系统既减少了必须由外部热源提供给气体的热量，也减少了必须由冷却系统排除的废热。因此，燃料消耗得以降低，工作循环的整体效率得以提高。

### 5.1.2. 优点

• 热量的供给始终来自外部，因此燃烧排放极少且灵活。

• 可使用任何热源工作，不仅通过燃烧，还可以利用诸如太阳能、地热能、核能、生物能等热源。

• 可采用连续燃烧过程，加之循环是封闭的，这使得排放可以大幅减少。

• 机构简单，比其他往复式机器更简单，因为不需要阀门，且燃烧器可以简化。

斯特林机器使工作流体处于单一相态，使内部压力保持接近设计压力，从而降低了爆炸风险。与蒸汽机不同，它不以液态和气态（蒸汽）的水工作，爆炸风险极小。

• 噪声水平低且无振动，使其成为非常安静的发动机。

• 效率非常高，因为斯特林发动机可以达到非常接近理想卡诺效率的效率。

### 5.1.3. 缺点

斯特林发动机需要入口和出口换热器，这些换热器必须使工作流体保持在高温下，同时能够承受热源和大气的腐蚀作用。这导致材料价格上涨。

• 冷端的散热较为复杂，因为冷却剂需保持在尽可能低的温度以提高热效率。

• 斯特林发动机不能瞬时启动，因为必须先加热。这是所有外燃式发动机的共同特点。

• 斯特林发动机所做的功趋于恒定，要对其进行调节需要精心的设计和额外的机构。

在发动机制造中，要在整个使用寿命期间封闭工作流体存在困难，这提高了发动机的成本。

• 发动机的点火和停机需要较长的时间。

• 时至今日，这类发动机的制造仍然缺乏经验。

## 5.2. 配置

存在三种配置类型：Alpha、Beta 和 Gamma。此外还有一些特殊配置，它们组合了上述两种配置。

### 5.2.1. Alpha 配置

这种类型的发动机有两个活塞，略有不同，但依据相同的热力学原理工作。区别在于它不像罗伯特·斯特林的原始专利那样使用置换器。它由两个通过管道连接的独立气缸组成，回热器位于该管道中，用于储存和释放热量；每个气缸中各有一个活塞，它们彼此错开90度运动。

其中一个气缸通过燃气或酒精点火器加热，另一个气缸通过散热片或水冷却。

### 5.2.2. Beta 型配置

活塞与置换器位于同一气缸内。发明者罗伯特·斯特林 (Robert Stirling) 制造的第一台发动机即属于这种类型。

置换器与功率活塞呈同心布置。置换器的作用是将空气从冷区传递到热区，反之亦然。通过一个特殊的曲轴，活塞与置换器的运动相位相差 90 度，从而实现运转。

从热力学角度来看，这是效率最高的发动机，但其结构也最为复杂。

### 5.2.3. Gamma 型配置

活塞与置换器位于不同的气缸中。这是一种由 Beta 型衍生而来的配置，但从机械角度而言更易于制造。在这种配置中，功率活塞的制造要简单得多，因为它与摩托车发动机的活塞类似。同样，在这种情况下，活塞与置换器也相差 90 度相位，这通过合适的曲轴来实现。

它由两个相互分离的气缸组成，其中一个放置置换器，另一个放置功率活塞。加热与冷却系统与 Beta 型配置相同。

从热力学角度而言，它的效率低于 Beta 型配置，因为功的膨胀全部是在较低温度下完成的。

## 5.2. 斯特林循环

斯特林发动机遵循著名的斯特林循环运行。该循环追求最大效率，与卡诺循环的效率相近。斯特林循环的效率对外界温度敏感，因此在寒冷气候下的效率要优于炎热气候。

所有以斯特林循环运行的发动机都是闭式循环发动机。在这些发动机内部存在固定量的空气，既不增加也不减少。因此，流体（空气）从一个热源到另一个热源的传递过程均在定容条件下进行。活塞与置换器同时运动且速度相同，彼此之间保持距离不变。如果因任何原因产生变化，由于压缩损失进而导致能量损失，回路将无法工作。

如下一图所示，斯特林循环可划分为 4 个点，即下文所述的 4 个步骤。

![](images/89946b66434c43b027bf320941727fd836ef0476710574d8c4041dd746303758.jpg)

图 16：斯特林循环，P-V 图与 T-S 图。

1-2：低温等温压缩，即较低温度，向冷源放热。

2-3：定容加热，其结果是压力升高。

3-4：高温等温膨胀，即较高温度，从热源吸收热量。

4-1：定容放热，将流体温度降至最低温度。

在斯特林循环中，若回热器的效率 e = 1，则其效率等于卡诺循环的效率。这是因为定容过程吸收与放出的热量相同，即 q1 (2-3) = q2 (4-1)，也就是说，它们在 T-S 图上覆盖了相等的面积。

## 5.3. 工作过程

本节根据活塞的位置解释发动机的工作过程。与斯特林循环一样，我们可以将其划分为四个步骤。

正如我们前面所述，斯特林发动机以闭式循环运行，通过四个连续的循环过程获得功：供热、借助热源供热的膨胀、向蓄热式回热器（回热器）放热，以及向冷源放热的压缩。

就斯特林发动机的概念示意而言，流体被限制在一个气缸内，位于两个相对的活塞之间。在中间，回热器将空间分隔开来，当流体穿过回热器时，回热器对其进行调节，使其适应所在腔室的温度。一侧是处于低温的压缩腔，另一侧是处于高温的膨胀腔。

![](images/0753207721b59695bcca4da4e365c543a7642a13beb10d08ff83727ff9db1915.jpg)  
图 17：斯特林发动机工作原理示意图。

在上图中（图 17）可以看到斯特林发动机一种可能的工作示意及其构成的四个步骤的演变过程。可以观察到功率活塞 (1) 与置换器 (2) 所采取的不同位置，以及冷腔 (3) 与热腔 (4) 的体积在每个步骤中如何演变。还可以看到回热器 (6)，它通过适配的通道 (7) 连接两个腔室，其中还有用于吸收和放出热量所需的元件 (5)。下面逐步详细说明。

位置 I。功率活塞处于下止点，置换器处于上止点。所有流体都位于冷腔中，因此冷腔体积最大，而热腔体积相应地为最小，即为零。

步骤 I-II。在冷腔中发生等温压缩过程（温度相同而体积不同），因此必须放热。

位置 II。置换器停留在上止点，功率活塞推进至上止点，在低温下压缩流体，流体的体积将最小，但冷腔的体积为中等，而热腔仍保持最小体积。

步骤 II-III。流体以等容方式（体积相同而温度不同）从冷腔转移到热腔。流体穿过回热器，回热器向它供热使其达到高温，这样流体便以其自身温度进入热腔。

位置 III。功率活塞保持在同一位置（上止点），置换器朝其下止点推进，让流体进入热腔（但并未到达，而是停在半途）。流体仍保持最小体积。热腔的体积增加到其中间体积，而冷腔的体积变为零。

步骤 III-IV。在热腔中发生等温膨胀（温度相同而体积不同），因此必须供热。

位置 IV。流体在穿过回热器时被加热，从而对置换器产生压力，迫使它现在真正推进到其下止点，功率活塞也同样推进至其下止点。

步骤 IV-I。置换器向其下止点移动，使全部流体穿过回热器到达冷腔。当置换器到达其上止点时，我们又回到了与 I 相同的结构。流体以等容方式（体积相同而温度不同）发生转移。流体穿过回热器并使其冷却，这样热量便积蓄在回热器中，直到流体再次通过时再向流体交还热量。

上述过程在某种程度上取决于发动机的配置，但在所有配置中都遵循相同的原理和工作过程。在所有情况下，功都在循环的 2-3 和 4-1 步骤中输出。

另一个不利于斯特林发动机效率的因素是死容积的存在。已经证明，有一部分流体体积是活塞无法推动的，因为它从侧面泄漏出去而成为死容积。这部分体积不参与循环，因而导致更大的低效率。消除这些死容积实际上是不可能的，因此必须做的是尽量将其减到最小。


在我们的模型中，当压力达到最大值时，正是活塞刚刚将力传递给动力轴的时刻。紧接着必须释放压力，这通过置换器向其止点（上止点）前进并将流体推向冷腔来实现。一旦置换器到达其上止点，全部流体都位于冷腔中且处于最小压力状态。下一步是在冷温度下压缩空气，然后再次将其转移到热腔，使流体在热温度下重新达到最大压力。流体中的压力差以及飞轮和机器外部将辅助活塞的所有运动，并促使动力活塞上升以产生最大压力，从而将力传递给系统。

### 6.1.1. 机械模型

机械模型，顾名思义，涉及发动机的机械部分，即描述发动机的整个机械系统，其主要目标是将来自热力循环的热能转化为机械能，随后这些机械能可以转化为电能。

正如在 Dymola 软件描述一节中所解释的，该软件提供了多个库，其中包含大量已创建的不同元件，可以直接使用，也可以根据每个用户的需求进行修改后使用。在我们的情况中，Dymola 提供了一种 V6 发动机类型，可以利用其中某个活塞的模型，只需进行少量修改即可完美适配我们的模型。该发动机来自 Modelica->Mechanics 库，更具体地说：Modelica-> Mechanics -> MultiBody -> Examples -> Loops -> EngineV6。

因此，我们的机械模型由两个从上述 V6 发动机中提取的完全相同活塞组合而成，用于模拟我们斯特林发动机中的两个活塞（动力活塞和置换器）。此外，还添加了一个曲轴和一个气缸或外壳。在附录 1 中更详细地解释了每个组件、构成这些组件的各个部分、它们之间的相互作用，以及对机械模型运行的分析。

## 6.2. 参数化与优化。

在分析、研究并理解了前两位工程师 Albert 和 Antía 所做的全部工作之后,我将着手改进和优化该模型。

就我们目前所处的阶段而言,发动机的热力学部分已由 Antía 进行了详尽的分析,而我所剩下的工作则是改进模型的机械部分,同时改进整个模型在 Dymola 软件中的实现,从而为将来希望使用该模型的用户节省工作量、优化仿真过程,并促进整体模型中各子模型之间的交互。

当前项目可以分为两部分:一是参数化,用于改进模型在 Dymola 中的实现;二是优化,用于获得该发动机最合适的机械特性。

### 6.2.1. 参数化

这部分的主要目标是修改并改进整个用 Dymola 编程构建的模型的设计。

首先,我们面对的是一个能够正确仿真和运行的模型,但其编程方式效率很低。也就是说,某个影响模型不同层级的参数或变量,在某一处被修改后并不会传播到所有层级,而是必须逐处修改该参数或变量,才能使其对整个模型生效。可以想见,在进行大量仿真时,这种编程方式确实非常不便,并且很容易导致出错。

另一方面,就机械模型而言,其各个参数或变量彼此之间没有关联,因此例如在修改行程时,活塞长度或直径并不会随之改变,从物理上讲你就可能得到一个完全荒谬、毫无可能正常工作的发动机。这是因为最初构建机械模型时,直接采用了另一台已知能正常工作的发动机的各项物理尺寸数值,并将它们固定下来。因此,我重新设计了机械模型,使所有参数和变量彼此关联,修改其中一个即可影响整个机械模型。

**a) 机械模型的重新设计**

如前所述,机械模型必须重新编程。重新编程时,利用了已知能够正常工作的各个参数/变量的现有数值,并通过提取方程将它们彼此关联起来。编程方式使得所有机械参数都随曲轴旋转半径变化,并且针对两个活塞分别处理:一个是功率活塞的曲轴半径,一个是置换器的曲轴半径。

在本节中，一旦完成模型参数化，我们将进行不同的仿真，以优化发动机机械参数的值。但在此之前，将先进行一些改变 Damper（阻尼器）值的仿真（它反映了发动机输出的功率），以便能够建立一条功率曲线。

**a) Damper 仿真**

在之前的项目中，还有一项未完成的工作：用不同的 Damper 值进行研究，以获得多个角速度和输出功率的平均值点，据此可以确定一条比之前未参数化模型可靠得多的功率特性曲线。

为进行该仿真，使用了一个 script.mos 脚本。该脚本包含了适当的编程，以便与 Model\_Final\_Stirling 一起执行，并针对所需的不同值进行一系列仿真，此外还能以 Dymola 格式和 txt 格式提取所需的结果。在我们的情况下，针对 8 个不同的 Damper 值进行了 8 次仿真，从 0.5 到 4.0，步长为 0.5，并提取了转速（revolute.w）和输出功率（lossPower）的结果。下图可以看到该脚本的代码。

```javascript
// Execució de les simulacions
Advanced.StoreProtectedVariables:=true; // per que no es quedi bloquejada la simulació al final
pos=1;
for d in 0.5:0.5:4 loop
tempsFinal=80;
res_f="Simulacio"+"_Damp_"+realString(d,precision=2);
intervals=50*tempsFinal;
simulateExtendedModel(problem="Model_Final_Stirling", stopTime=tempsFinal,
method="dassl",numberOfIntervals=intervals,
initialNames={"damper.d"}
initialValues={d}.
finalNames={"damper.lossPower"}.
resultFile=res_f,autoLoad=false)
mysignals = {"Time", "damper.lossPower", "inertia.w", "damper.d"}:
n=readTrajectorySize(res_f+".mat");
traj=readTrajectory(res_f+".mat",mysignals,n);
writeCSVFileInternal(res_f+".txt",mysignals,transpose(traj),separator="");
closeModel();
pos=pos+1;
end for;
```

# 结论

在完成本项目之后，我们可以得出结论。着眼于具体目标，可以说我们已全部完成，具体如下：

已认识并学会在 Dymola 软件的各个环境中使用它。

• 已完全理解斯特林发动机及斯特林循环在机械和热力学两方面的工作原理。

• 已研究并分析了本项目之前的所有前期工作。

• 已成功将整个模型参数化，如今它以更为协调的行为运行，能够正确仿真，且更容易避免错误。

• 已进行了一项详尽的仿真研究，以得到期望的结果。

• 已得到一个性能更好的发动机原型，具有更高的转速以及输出功率的提升。

至于总体目标，即得到一个功能正常、切实可行、性能可靠且可移植到现实世界的发动机模型，我们必须说目前尚未实现。无论如何，在本项目之前的两个项目中它也未能实现，因为这是一件非常复杂的事情，还需要若干个项目才能达到最终目标并将其变为现实。

作为个人评价，我想谈一下，我对完成的项目感到非常满意，这是一个我觉得非常有趣、且此前未曾想到会如此有趣的主题，它帮助我巩固了在仿真、力学和热力学领域的旧有知识，同时获得了新的知识，这些知识在不久的将来必定会对我有用。我认为这是一个非常有趣的主题，尤其是仿真方面，因为它可以用于无数领域，而且很明显未来正在朝着这个方向发展。

# 第8章 未来改进

本项目未来的研究应致力于继续改进和优化整个模型，无论是像 Antía 在其项目中所做的那样改进热力学模型，还是像本项目这样改进机械模型，或是同时改进这两个模型。

此外，迟早纳入一个回热器将是非常重要的。

从长远来看，应利用在热力学模型和机械模型中获得的参数来建立一个具有高效率且更贴近实际的发动机原型模型。

## 1.4. 附录1.1 机械模型

## 3.4. 模型.

既然我们已经理解了发动机的工作原理并熟悉了该程序，就可以开始其在 Dymola 中的设计或实现。为了简化系统的创建和说明，我们将其划分为两个更简单的模型或子系统，分别称为：机械模型和热力学模型。

### 3.4.1. 机械模型.

机械模型.

顾名思义，它是负责描述系统机械部分的模型。对于该系统的建模，我们没有创建任何新的组件或模型，而是复用了 Dymola 现有库中的模型和组件（具体为 Modelica-> Mechanics 中的模型和组件）。

机械模型的作用是将热能转化为机械能，随后我们将利用这些机械能转化为电能。

机械模型主要由四个组件组成：压缩活塞、膨胀活塞（或置换器）、曲轴以及气缸（或外壳）。

• 压缩活塞.

它是负责承受气缸内部压力的元件，该压力转化为作用于活塞上的力，从而驱动整个系统运动。它位于发动机的冷端。组成它的元件如下：

![](images/91c300ba3df52a703fca63e702cb83b5a72e7b86f63d1482c5a11797487990ed.jpg)  
图 11 活塞的装配.

b) 连杆：连接活塞头与曲柄销（曲拐）或曲柄的元件，将活塞头的直线运动传递给曲轴，因此该元件必须能够承受压缩和弯曲应力。设计连杆时的一个重要因素是，其长度应等于曲柄所描述的旋转直径的两倍。

![](images/5b3c71547b8dc517ebbbc83b1a42544ea91354c21f54ba7f94cb4b0d93a34d88.jpg)  
图 13 连杆.

c) 轴承：通过滚动体减少轴与连接件之间摩擦的连接元件。它起支撑作用，并便于两者之间的相对移动。它们位于活塞销与连杆之间以及连杆与曲轴之间。

![](images/ffd4487d96472bb27db62cc9b40450a94b120adbe096fd74cc118993d1dd9bb9.jpg)  
图 14 轴承的剖视图.

**• 膨胀活塞（或置换器）。**

它是机械模型中负责将空气从一个区域移向另一个区域的元件。由于压缩活塞使曲轴产生运动，曲轴将该运动相应地传递给置换器。该运动的周期与压缩运动相同，但相位差为 90º，正如 beta 型发动机的规格所示。

组成置换器的元件与动力活塞的元件相同。

**• 曲轴**

发动机中连接两个活塞的部分。它承受压缩活塞的爆发力并将其转化为旋转运动。该旋转运动又转化为传递给置换器的直线运动，从而使一个活塞的位置与另一个活塞的位置相互关联。

![](images/5df09ba9e1d92fa2a658d99230d9100323e9f761089a6ac765e5c2106763d2c8.jpg)  
图 15 斯特林发动机的曲轴.

**• 气缸.**

我们将气缸定义为发动机的外壳或保护元件，负责保护发动机免受外部因素的影响，完善发动机的几何形状，并将外部的热量传递给内部气体。

一旦确定了发动机的各个部分，我们就可以理解整体之间的相互作用。

![](images/36962e3e97691a7879fd0e29e099ad194285768fab4ff48f28dc9197d671337f.jpg)  
图 16 机械配置的俯视图.

![](images/5399fafebfd80aab6fe7866e03c4b131fea6cfaa235a0e373df97a601404ef3d.jpg)  
图 17 机械配置的侧视图.

机械模型的工作原理分析：

压力所产生的力使压缩活塞头产生直线运动，从下止点（PMI）运动到上止点（PMS），该运动在曲轴上表现为圆周运动

![](images/6c518d1860eb5c558fb11edd12d7e65a765759f2afcbe82d9a79c5fb86b618e2.jpg)  
图 18 斯特林发动机动力活塞运动的描述

活塞头所受到的力为：

$$
F = P 2 ^ { * } A 2
$$

其中：

P2= 活塞区域的压力.

A2= 压缩活塞的面积.

对作用力进行分析后，我们发现作用在压缩活塞头上的力可以描述为该力与压缩活塞头纵轴及其连杆之间夹角的乘积：

![](images/faa40ed1d0676ef217533de32da0ebc79170cdc1a5a55f9ed93c74dee58f0ba9.jpg)  
图 19 分析截面的细节.

应用三角学，我们发现可以根据连杆和曲轴的长度来描述活塞头的纵轴：

$$
X = \sqrt { l ^ { \mathrm { A } } 2 - B ^ { \mathrm { A } } 2 ^ { \mathrm { ~ + ~ } } 5 e n ^ { \mathrm { ~ A } } 2 \bar { \theta } }
$$

$$
x = l ^ { 2 } - \infty , 0 \in \mathbb { C }

$$

最后，已知传递到轴上的扭矩等于该轴所受的力与距离的乘积，可得传递到曲轴的扭矩为：

$$

T = P 2 ^ { * } A 2 ^ { * } \frac { B } { \sqrt { l ^ { \sim } 2 - B ^ { \sim } 2 ^ { * } s e n ^ { \sim } 2 \theta } } { * ( \frac { B ^ { * } s e n ^ { \sim } 2 \theta } { 2 } + s e n \theta ^ { * } \sqrt { l ^ { \sim } 2 - B ^ { \sim } 2 ^ { * } s e n ^ { \sim } 2 \theta } ) }
$$

根据气缸和活塞的几何关系，确定上止点（PMS）和下止点（PMI）。结合上述公式，我们就能根据作用力来描述压缩活塞的新位置，并根据压缩活塞的位置来描述置换器的新位置。

……该模型，因为它不承受任何由压力产生的力，而只是将体积从一侧移动到另一侧（由置换器引起的体积移动，我们将在第 3.4.2 节中描述的热力学模型内加以定义）。

我们取当前带动 V6 活塞的气体模型，将其复制到一个新模型中，命名为 ModelConnectors\_Forces。在该模型中，我们删除全部现有代码，并引入一个新的输入（Modelica-> Blocks-> Interfaces-> Real Input），该输入将是斯特林循环提供给我们的力，我们将使其等于该气体输出的力。这样做是为了利用气体模型中已编程好的连接器，以便与机械模型的其他组件相连接。

## 1.5. 附录 1.2. 热力模型

### 3.4.2. 热力模型

热力模型是发动机中最重要的部分，因为它将为我们提供作用力以及工作温度。这一部分是从零开始建模的，因为 Dymola 没有任何与气体工作所依据的斯特林循环相类似的模型。

为了实现该模型，将其分成了两个部分。第一部分只对质量运动建模，即在恒温条件下，根据置换器的运动在每个区域所赋予的体积来确定质量运动。第二部分对各区域质量的加热和冷却进行建模，这取决于每个区域中可用的体积。

**• 第一部分，质量运动：**

基于前述机械模型的构建，我们知道需要将该机械模型中的活塞位置与热模型中的活塞位置关联起来，热模型将给出每个区域的可用体积，并返回一个合力。因此，我们需要第一个模型，称之为 ModelConnector_Posicions_Forces，用于将这些位置输入关联到热力模型，并将该模型的力输出关联到机械模型。

![](images/f29e122d96fe7c455e0127238eefc98c001a7571d7ecaa6706a08a3a780d1830.jpg)  
插图 30 ModelConnectors\_Posicions\_Forces 的代码。

其中：

u = 功率活塞相对位置输入

u1 = 置换器相对位置输入。

fo = 热力模型输出的力。

一旦将模型的输入和输出关联起来，我们就通过创建一个名为 ModelVolums 的新模型来对体积运动进行建模。观察机械模型研究得出的曲线图可以看到，这些位置描述了一个彼此相位差 90° 的正弦运动，其中置换器处于其最大位置，而功率活塞处于其最大位置的一半。由于目前我们分别研究各个模型，因此将这些位置的输入设定为一个常数，乘以时间，并将其变换为正弦波，且对其中一个相对于另一个进行 90°（π/2）的移相。

该运动描述如下：

// 位置输入。   
sd = (1+sin(u1\*time+3.1514/2))/10;   
sp = (1+sin(u\*time))/10;  
插图 31 ModelVolums 位置输入代码。

对正弦值加 1 以使其全部为正，并将两个输入的值除以 10，以将数值量级调整到更真实的值。因此，一旦我们知道如何描述这些相对位置，并观察机械模型的初始几何形状，就能够知道有哪些常数参数，以及它们在两个模型之间是如何关联的。
