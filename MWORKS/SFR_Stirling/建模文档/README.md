## 4 维护约定

1. **单一基准**：新增/修改文档前先对照 `Base.mo` 的组件与实例参数；不在链上的模型（β 型 `Gas_Dynamic`、`DA_Engine`/`v2`、`StirlingEngine`、`MechanicalGas`、`TubeWall` 独立用法）不再单独建文档，只在相关文档的“版本/局限”里提一句；
2. **一组件一篇**：同一组件的多代版本合并；历史数值只放在“标定历程/版本演进”表里，并标注对应日期与对象；
3. **参数出处**：所有关键参数注明来源（论文表号/标定日期/Base.mo 实例值）；无法确认的写“假设/待确认”，不要静默取整；
4. **归档**：被取代的文档移入 `_归档/`（保留原名），不直接删除；
5. **验证数据**：仿真结果注明模型名、时长、取样区间；跨版本引用必须写清“旧参数/新参数”。
