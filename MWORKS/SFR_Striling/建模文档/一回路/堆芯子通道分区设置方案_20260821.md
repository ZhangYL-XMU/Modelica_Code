# 堆芯按子通道类型细分设置方案（侯斌论文 ↔ TRANSFORM SFR ↔ 当前 FirstLoop 比对）

任务编号：SFR-20260821-01（堆芯子通道分区方案设计）
生成时间：2026-08-21
用途：为 `SFR.Structure.Closed.FirstLoop` 的堆芯从"热通道 + 平均通道"双管模型升级为"屏蔽层 / 反射层 / 内堆芯 / 外堆芯"四类子通道分区模型提供设计依据与参数设置方案。本方案不修改任何已有模型库，仅给出新建模型的配置建议。

---

## 1 结论与方案要点（先给结论）

1. **三方比对结论**：
   - 当前 `FirstLoop.mo` 的堆芯是**双通道点堆模型**（`pipe1` n_pipe=30 热通道 + `pipe2` n_pipe=180 平均通道），其直接来源是尹凯论文 RELAP 节点 104（最热燃料组件）/ 105（其他燃料组件），**没有屏蔽层与反射层流道**（RELAP 节点 106"除燃料组件外其他堆芯流道"未建模）。
   - 当前模型热通道功率份额 $0.19085525$ 与侯斌论文表 3 **第 8 圈功率份额 $7634.21/40000=0.19085525$ 完全一致**，即"热通道"对应最外圈。
   - TRANSFORM 库自带 `TRANSFORM.Examples.SodiumFastReactor.SFR` 示例，用 `Nuclear.CoreSubchannels.Regions_2`（燃料组件：燃料芯块 + 包壳两固体区）和 `Regions_1`（非燃料组件：单固体区）构成 **shield / reflector / outerCore / innerCore 四类并联子通道**，正是"按子通道类型细分堆芯"的现成范本，可直接照搬其结构并替换为侯斌论文参数。

2. **四区设置核心结论**（按侯斌论文表 3 圈功率分布 + 图 2/图 3 的 OCR 识别结果）：
   - **内堆芯 innerCore**：圈 1~4，燃料组件约 36~37 个（图 2 显示中心圈 1 的 1 个位置为控制棒组件，若确认则燃料 36 个），$Q_{inner}=8948.31\ \text{kW}$，`Regions_2`，UO2 + SS316；
   - **外堆芯 outerCore**：圈 5~8，燃料组件约 102~103 个，$Q_{outer}=31051.69\ \text{kW}$，`Regions_2`，UO2 + SS316；
   - **反射层 reflector**：12 个反射组件（$Q=0$，`Regions_1`）——**材料存在矛盾：图 2 图例标注为"钢反射层"，正文又称"铍反射层"，需用户目视图 2 确认**；
   - **屏蔽层 shield**：`Q=0`，`Regions_1`——图 2 标注为"**模块化屏蔽围桶**"（其外还有"防铁窗效应夹层"），图 3 显示屏蔽体轴向为"**硼钢（铅）+ 氢化（锆）夹层 + 硼钢（铅）**"三段结构；组件数论文未给出，**建议按外围 1 圈取 42 个起步，需对照论文图 2 数格子确认**。
   - 各区间功率份额：$\phi_{inner}=22.37\%$、$\phi_{outer}=77.63\%$。

3. **两个设计点都要覆盖**：侯斌论文原始设计（400/550 ℃、210.6 kg/s）与尹凯论文细化设计（440/550 ℃、280.6 kg/s）不一致；**当前 `FirstLoop` 采用尹凯版**（pump `m_flow_nominal=280.6`、IHX 二次侧 308.4 kg/s），升级时应保持尹凯版回路参数不变，仅重排堆芯分区，以免破坏已调通的回路稳态。

4. **改动最小的集成方式**：保留现有全局 `SFR.Nuclear.PointKinetics` 与 PID 棒控闭环，四个子通道分区的 `specifyPower=true`、`alpha_fuel=alpha_coolant=0`，仅作为"功率分配 + 热工水力"的细化层，功率输入为 `Q_total × 分区份额`。

## 2 三方堆芯建模方式比对

### 2.1 当前 FirstLoop（双通道点堆）

`E:\Modelica Code\MWORKS\SFR_Stirling\Structure\Closed\FirstLoop.mo` 中堆芯由以下构成：

| 组件 | 作用 | 关键参数 |
|---|---|---|
| `pipe1` | 热通道 | `n_pipe=30`、N=5、h_start=4.725e4 |
| `pipe2` | 平均通道 | `n_pipe=180`、N=5、动量稳态 |
| `pointKinetics` | 全局点堆 | `Q_HotChannel = Q_total × 0.19085525`；`Q_AverageChannel = Q_total − Q_HotChannel` |
| `prescribedHeatFlow / prescribedHeatFlow1` | 热流注入 | 分别接 `pipe1.wall[1]`、`pipe2.wall[1]` |
| `volume / volume1` | 上 / 下腔室 | 两管并联于上下腔室之间 |

`SFR.Nuclear.PointKinetics.mo` 第 125~126 行：

$$
Q_{Hot}=0.19085525\,Q_{total},\qquad Q_{Avg}=Q_{total}-Q_{Hot}
$$

而侯斌论文表 3 第 8 圈份额 $\dfrac{7634.21}{40000}=0.19085525$，**精确相等**，证实"热通道 = 第 8 圈（最外圈）"。

### 2.2 尹凯 RELAP 模型（当前模型的文献来源）

尹凯论文（建模及安全特性研究）表 2 的 RELAP 节点划分：

| 节点 | 含义 |
|---|---|
| 102/103 | 下栅板联箱 / 堆芯入口体积 |
| **104** | **最热燃料组件**（← 当前 `pipe1`） |
| **105** | **其他燃料组件**（← 当前 `pipe2`） |
| **106** | **除燃料组件外其他堆芯流道**（屏蔽 / 反射 / 围板冷却，当前模型缺失） |
| 107 | 堆芯出口体积 |

即尹凯模型本身是三通道（最热 / 其他燃料 / 非燃料流道），当前 `FirstLoop` 只实现了前两个。

### 2.3 TRANSFORM SFR 示例（四类子通道）

`E:\华为云盘\MWORKS_File\TRANSFORM\Examples\SodiumFastReactor\SFR.mo` 的堆芯段（第 21~156 行）：

| 分区 | 模型 | nParallel | 材料 | Q_nominal | 几何 |
|---|---|---|---|---|---|
| `outerCore` | `Regions_2` | nOuterCore=42 | UO2 + SS316 | 180 MW（60%） | Assembly 六角，271 棒，active 0.8 m |
| `innerCore` | `Regions_2` | nInnerCore=30 | UO2 + SS316 | 120 MW（40%） | 同上 |
| `reflector` | `Regions_1` | 180 | SS316 | **0** | Assembly，`rs_outer={0.5·D_pin}`（实心钢棒），length_total |
| `shield` | `Regions_1` | 126 | SS316 | **0** | 同上 |

要点：
- 四个分区**并联**于下腔室（经 `resistances[4]` 分配流量）与上腔室之间；
- 传热关联式统一用液态金属 `Nu_FFTF`（丝缠棒束，FFTF 经验式）；
- 流量分配阻力：`R = {2e5/m_shield, 2e5/m_reflector, 1/m_outer, 1/m_inner}`（屏蔽 / 反射给大阻力小流量）；
- 内、外堆芯各带独立点堆（`specifyPower=false`），反射 / 屏蔽 `Q=0`；
- 流量份额 `R_m_flows = {0.5, 0.3, 0.1, 0.1}`（外 / 内 / 反射 / 屏蔽）。

### 2.4 模型机理说明（TRANSFORM 子通道）

- `Regions_2`（`TRANSFORM.Nuclear.CoreSubchannels.Regions_2`）：一个"等效冷却剂通道 + 两固体区（燃料 + 包壳）"的 1-D 组件模型。`nParallel` 为并联组件数；内部自带 `PointKinetics_L1_powerBased`（`specifyPower=true` 时不解功率微分方程、直接使用 `Q_fission_input`）、`GenericPipe_MultiTransferSurface` 冷却剂通道、`FuelModels.Regions_2_FD2DCyl` 燃料棒 2-D 圆柱导热。
- `Regions_1`：单固体区版本（`final nRegions=1`），供无燃料组件的反射 / 屏蔽通道使用，`Q_nominal=0`。
- `Geometry = Assembly`（`Nuclear.ClosureRelations.Geometry.Models.CoreSubchannels.Assembly`）按六角导管自动计算流道：

$$
A_c = A_{duct}-n_{pin}\pi r_{clad}^2-\frac{\pi}{4}D_w^2 n_{pin},\qquad
A_{duct}=\frac{3\sqrt{3}}{2}\left(\frac{w}{\sqrt{3}}\right)^2=\frac{\sqrt{3}}{2}w^2
$$

$$
P_{wet}=6\frac{w}{\sqrt{3}}+2\pi r_{clad}(n_{pin}+n_{pin,nonFuel})+\pi D_w n_{pin},\qquad
D_h=\frac{4A_c}{P_{wet}}
$$

  其中 $w$=`width_FtoF_inner`（导管内对边距）、$r_{clad}$=`rs_outer[end]`。
- 反馈系数单位：`TRANSFORM.Units.TempFeedbackCoeff` 为 $1/\text{K}$，与当前 `SFR.Nuclear.PointKinetics` 的 `alpha_fuel=-2.5\times10^{-5}$、`alpha_coolant=-20\times10^{-5}$（1/K）同量纲同默认值。

## 4 四区设置方案（核心）

### 4.1 分区架构

```
下腔室 lowerPlenum（volume1）
   ├─ resistances[1] ─ shield     (Regions_1, Q=0)      ─┐
   ├─ resistances[2] ─ reflector  (Regions_1, Q=0)      ─┤
   ├─ resistances[3] ─ outerCore  (Regions_2, 31.05 MW) ─┼─ 上腔室 upperPlenum（volume）
   └─ resistances[4] ─ innerCore  (Regions_2, 8.95 MW)  ─┘
```

与 TRANSFORM 示例完全同构；流量由各通道阻力（`SpecifiedResistance.R` + 组件自身流阻）分配。

### 4.3 流量分配

按"各燃料区出口温度一致"原则：$m_i=\dfrac{Q_i}{c_p\,\Delta T_i}$，反射 / 屏蔽流道按结构冷却份额（约各 1.25% 总流量）估算，并用阻力 `R` 配平。

**尹凯设计点（当前 FirstLoop，440→550 ℃，$\Delta T=110$ K，总流量 280.6 kg/s，$\bar c_p\approx1296$ J/(kg·K)）：**

| 流路 | 流量 kg/s | 份额 |
|---|---|---|
| 外堆芯 | **212.4** | 75.7% |
| 内堆芯 | **61.2** | 21.8% |
| 反射层 | 3.5 | 1.25% |
| 屏蔽层 | 3.5 | 1.25% |

校验：$Q_{outer}/(m_{outer}c_p)=31051.69\times10^3/(212.4\times1296)=112.8$ K，燃料区出口 552.8 ℃，与 550 ℃ 偏差约 0.5%（在尹凯论文 1% 验证标准内；若要求精确配平，按 $m_{fuel}=Q_{fuel}/(c_p\times110)$ 反推后微调两路非燃料流道份额即可）。

**侯斌设计点（400→550 ℃，$\Delta T=150$ K，总流量 210.6 kg/s，$\bar c_p\approx1266$ J/(kg·K)）：**

| 流路 | 流量 kg/s |
|---|---|
| 外堆芯 | **159.4** |
| 内堆芯 | **45.9** |
| 反射层 | 2.6 |
| 屏蔽层 | 2.6 |

流量分配阻力（TRANSFORM 式写法，`SpecifiedResistance` 数组，单位 (Pa·s)/kg）：

```modelica
R = {2e5/m_flow_shield, 2e5/m_flow_reflector, 1/m_flow_outer, 1/m_flow_inner}
```

其中 `m_flow_*` 取上表各区流量。屏蔽 / 反射的大阻力系数 $2\times10^5$ 保证其小流量；燃料区阻力主要由组件几何（61 棒 + 丝缠压降关联式 `SinglePhase_Developed_2Region_NumStable`）自然形成。

### 4.4 功率输入与反馈接线（保持现有控制闭环）

- `pointKinetics.Q_total` → `gain_inner`（k=0.2237）→ `innerCore.Q_fission_input`；
- `pointKinetics.Q_total` → `gain_outer`（k=0.7763）→ `outerCore.Q_fission_input`；
- `reflector / shield` 无功率输入（`Q_nominal=0`）；
- 温度反馈维持现状：`TSensor2.T`（堆芯出口）→ `pointKinetics.Teff_coolant`；`Teff_fuel` 维持定值输入（与现有 `const2` 相同）；**四个分区自身的 `alpha_fuel/alpha_coolant` 全部置 0**，避免反馈被重复计算。

若后续希望把反馈细化到"内 / 外区各自燃料温度 + 钠温"（TRANSFORM 例的原生方式），则改为：全局点堆只算棒位反应性，`alpha_fuel/alpha_coolant` 置 0；各区 `specifyPower=false`、恢复各自 `alpha`（$1/\text{K}$，可用当前库同值 $-2.5\times10^{-5}/-2\times10^{-4}$）。此为可选项，默认不启用。

### 9.4 搭建提示

1. 新建模型 `SFR.Structure.Closed.FirstLoop_fixed`，或复制 `FirstLoop` 后：删除 `pipe1/pipe2/prescribedHeatFlow/prescribedHeatFlow1/gain/gain1/realExpression2`，按 §9.2 加入堆芯 7 管与分配阻力、功率增益/热源；`volume` 的 `nPorts_a` 改 3、`volume1` 的 `nPorts_b` 改 3。
2. 动量设置（最终版，与 `FirstLoop_fixed.mo` 一致）：主回路 `pipe_static1/2` 与 HE1 壳侧用 `SteadyState`（泵锁流量并联分流）；堆芯七管用 `DynamicFreeInitial` 并给 `m_flow_start` 单管初值（屏蔽 0.13 / 内 1.65 / 外 1.86 kg/s）——全 `SteadyState`+泵锁流量+三路并联阻力的组合会使初始化代数难收敛（卡 t=0），动态动量让流量成状态、直接取初值（与 FirstLoop 热通道管一致）。
3. 仿真设置沿用 FirstLoop：Dassl、0~3600 s、Tolerance 1e-4；400 s 处 ramp 引入 +4 MW 阶跃扰动用于验证控制闭环。
4. 稳态验收：满功率 40 MW、堆芯出口 TSensor2≈550 ℃、内/外堆芯出口≈550 ℃（流量配平正确时两燃料区出口温度一致）。
5. 若要轴向功率非均匀（图 3 五段 300/200/100/200/300），把 `innerCore/outerCore` 的 N 改 6，4 个热源增益改为加权（如 0.3/0.2/0.1/0.2/0.3 归一化）；首版均匀即可。
6. 若后续仍需 TRANSFORM 子通道组件（燃料导热/点堆内置），需先按规则 2 新建一个 `nXi=1` 的钠介质包装包并全回路统一替换，再移植 §7 骨架。


### 9.5 修订记录（2026-08-21 复核，模型文件与本节参数表同步更新）

对 `SFR.Structure.Closed.FirstLoop_fixed.mo` 与 `SFR.Nuclear.PointKinetics.mo` 复核后的修正：

1. **功率分配修正（关键）**：原实现把 `pointKinetics.Q_innerCore`（=0.19085525，圈8 热通道份额，FirstLoop 双通道语义）直接送入内堆芯通道，与内/外堆芯 8948.31/31051.69 kW（0.2237/0.7763）不符；已改为 `gain_inner(k=8948.31/40000/4)`、`gain_outer(k=31051.69/40000/4)`，输入接 `pointKinetics.Q_total`（本方案 §9.2 原设计）。
2. **焓初值对齐设计点**：`pipe_static1/2` 原 h_start=4.725e4（≈336 K，FirstLoop 遗留）改为热段 656775（550 ℃）/ 冷段 519165（440 ℃）；`expansionTank` 469125（400 ℃，侯斌冷段遗留）改为 656775（热段）；`volume`/`volume1` 显式给定 656775/519165（原默认 800 K）。
3. **点堆方程修正**（`PointKinetics.mo`）：① 状态变量 `Q_fission` 补 `start=Q_nominal`（原 der(nt) 改为功率形式时丢失初值，导致从零功率启动，与设计点不符）；② `Reactivity_Other` 输入未计入 `Reactivity_Total`，已补入（FirstLoop_fixed 中 const1=0，不影响数值）；③ 注释标明 Q_innerCore/Q_outerCore 为 FirstLoop 热通道/其余通道语义。
4. **动量记录**：堆芯七管 `DynamicFreeInitial` + `m_flow_start` 单管初值（初始化收敛修正），主回路 `SteadyState`。
