## 2. 行为差异机理：热阱特性

| | 固定恒温入口边界（430 ℃） | 斯特林（冷端 50 ℃ 恒定 + U_h/U_c/U_reg 固定） |
|---|---|---|
| 排热需求对温度的响应 | 几乎不变（ΔT₂ 100→105.5 K） | **随温度自增强**（T_Na 530.2→554.6 ℃ ↔ 引擎吸热 +5~7%；Q_in 723.6→750~762 kW；η 32.8%→35.4%） |
| 流量 ↓30% 后 | 排热能力 ∝ 流量 → 功率被压至 29.5 MW | 排热需求不随流量降、随平台抬升 → 系统停在更高温度/更高功率（43.5 MW） |

因果链（已在数据上验证）：流量 ↓ → 传热系数 γ∝Re^0.8 ↓ → 同一功率下 ΔT₁/ΔT_wall 拉大 → 中芯瞬升 → 冷却剂强负 ρ 压功率（固定边界：压到 29.5 MW ✓；斯特林型：平台抬升使中芯假性回稳、引擎吸热增强，压不下去）→ 燃料壁温反馈零点移动 → 平衡功率由"排热需求曲线与堆芯反馈曲线交点"决定。

### 3.1 关键结论一：**SFR_flowDown 的行为与尹凯论文同族（不是"异常"，是可比的物理）**
- 尹凯论文报道：**排热能力下降（70% 流量）时核功率基本维持（0.989），以"温度平台上移"实现排热平衡**——堆芯出口 +23.5 ℃、温差 +43 K、IHX 二次侧出 +16.4 ℃；
- 我们的含斯特林模型复现了同一模式：功率 +8.3%、出口 +30.2 ℃、温差 +60.5 K、HE1 管侧出 +24.2 ℃——**方向、结构完全相同**；
- 修正 09-07 早期判断：**"流量下降后功率应自降"只在"固定温差热阱"下成立**（如 PrimaryLoop_flowDown/经典固有安全教材），**含斯特林的实际系统响应与尹凯论文一致：温度上升换散热、功率不降**（尹凯 -1.1% vs 我们 +8.3% 主要是无整定/无控制棒 + 参考零点额定标定 + 反馈口径差异）。

### 3.2 关键结论二：量级差异的来源（我们 vs 尹凯）
1. 我们 CR 恒 0 且无任何整定；尹凯 RELAP 含 16 缸斯特林+完整电站模型（有稳态调平），其功率微降（0.989）而我们 +8.3%；
2. 我们的反馈参考（863.2/768.29 K）按额定工况标定——跨工况时燃料反馈零点漂移（ΔT_wall 96→122 K）把平衡推向更高功率；尹凯的燃料反馈/RELAP 模型为宽工况自洽形式；
3. 我们的斯特林冷端恒 50 ℃ 且 U 恒定（同尹凯表6 冷却水 50 ℃——**这一点一致**，都是"固定冷端"热阱），但我们的 heff=1.41 等效与 d=10.6 负载使之在温度上升时吸热/功率增幅更大；
4. 温度量级：我们 Teff_fuel 617 ℃ 为**集总棒温**（非燃料中心/热点），与尹凯"燃料热点 1148.5 K（875 ℃）"不可直接比；从壁温口径看仍在合理范围（棒温上限约 700-800 ℃ 量级），安全裕度结论需按热点口径另算。

## 4. 结论

1. `PrimaryLoop_flowDown`（固定恒温入口热阱）：**功率 40.00→29.52 MW（−26.2%）**，平台 ±3 K——纯温度反馈下"功率随排热能力下降"的固有安全行为 ✓，能量闭合精确；
2. `SFR_flowDown`（斯特林固定冷端热阱）：**功率 40.17→43.51 MW（+8.3%）**，平台整体上移 24–30 K——**与尹凯论文 §4.2 同族行为**（尹：39.56 MW、+23.5 ℃），用温度上升换取散热；量级差异源于无整定/参考标定/引擎特性；
3. **固有安全口径建议**：若论文/报告需要"流量下降→功率自动下潜"的表述，应在"含斯特林"模型上改造热阱（冷端随流量衰减的变温/变 U）或二回路恒温差边界化（PrimaryLoop_flowDown 即证明该口径可行）；若按尹凯口径（温度上升、功率不降、壁温受限），SFR_flowDown 现状即为一致行为，需补充热点温升限值校核。
