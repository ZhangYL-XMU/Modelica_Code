# PrimaryLoop 无 PID 自稳定性验证（2026-09-06）

> 目的：回答「不使用 PID 控制，点堆能否在 40 MW 自稳、并自行修正扰动」——验证模型/系统自身的固有安全特性。
> 对象：`SFR.Structure.PrimaryLoop.PrimaryLoop`（文件夹式包 `Structure\PrimaryLoop`，一回路；2026-09-07 已按下方标定参数**直接改造到本体**：CR 恒 0、燃料壁温反馈、refs 863.2/768.29、热态初值 607863。同步存在已验证变体记录见 §1–5 与 §6 全系统版）。与全系统 SFR_Stirling 无关（后者的 300s/1000s 标定见 `换热器HE1标定_20260831.md` §6.4）。

## 1. 变体改动（相对 PrimaryLoop）

| 项 | 原模型 | 变体 |
|---|---|---|
| 控制棒反应性 | PID(NoInit)→limPID→`Reactivity_CR` | **constCR(k=0)** 恒 0（PID 旁路保留在图上） |
| 燃料反馈 | 常数 823.15（实际断开） | `0.2237·innerCore.T_wall[6] + 0.7763·outerCore.T_wall[6]`（与冷却剂 T[6] 同轴向点、份额加权） |
| Teffref_fuel | 864.05（TubeWall 时代残余） | **863.2 K**（本模型管道壁温口径稳态外推：Tw(40MW)=861.31+2.75×0.68） |
| Teffref_coolant | 767.18（TubeWall 时代残余） | **768.29 K**（本模型稳态 dT/dQ=1.64 K/MW，39.47→40.00 MW 需 +0.87 K；与原始 768.15"495℃"口径一致） |
| 初始热态 | 冷芯堆（注释 440℃ 实为 425.6℃）→ ρ₀≈+1100 pcm | 堆芯活性段 `h_start=607863`（中芯 T[6] 初值=额定 767.18 K，ρ₀≈0） |
| 初始功率 | Q_fission 固定 40 MW | `Q0_start` 参数（A=40e6 定值自稳 / B=44e6 扰动回归） |

> 重要发现（已写入注释）：**冷态无棒不能自稳启动**——默认初值（堆芯 425.6/506.8 ℃、壁温 298 K）在无 PID 时 ρ₀≈+1100 pcm，超瞬发临界，功率毫秒级发散。自稳性只在额定平衡点邻域成立（物理上正确：启动需控制棒）。

## 2. 标定过程（反馈参考温度迭代）

无 PID 时平衡点=ρ_fuel+ρ_cool=0，由冷却剂反馈主导（dQ/dTref_c≈0.6~0.67 MW/K，稳态 dT/dQ=1.64 K/MW）：
- Teffref_fuel=857 → Q∞=39.32 MW；→865.7 → 不变（冷却剂主导）
- Teffref_coolant 767.18→767.42→**768.29**、Teffref_fuel→**863.2** → Q∞=**40.004 MW**

## 3. 工况A：定值自稳（Q0=40 MW，无 PID，300 s）

| t | Q [MW] | ρ_总 | 备注 |
|---|---|---|---|
| 0 | 40.000 | ≈0 | 额定热态启动 |
| ~50 | 40.43 | −9.9e-5 | 微小扰动过冲 |
| 200 | 40.005 | −5.9e-6 | 反馈拉回 |
| **300** | **40.004** | −7.1e-7 | **自稳 ✓（+0.01%）** |

- 堆芯入口 **440.04 ℃**、堆芯出口 **550.05 ℃**、二回路出 HE1 530.09 ℃、Teff_fuel=864.05、Teff_coolant=768.29（=额定零点口径）
- **结论：无 PID 可自持 40 MW 额定点**（负反馈回路完整：燃料壁温（多普勒型）即时反馈 + 冷却剂反馈）。

## 4. 工况B：+10% 功率扰动回归（Q0=44 MW，无 PID，300 s）

| t | Q [MW] | 说明 |
|---|---|---|
| 0 | 44.000 | +10% 扰动注入 |
| 0.05 | 36.05 | 燃料反馈即时压降（壁温瞬时跳升→负ρ） |
| 0.2 | 24.02 | 瞬发压低 |
| 1~10 | 48.8 | **过冲峰值 ≈48.8 MW（+22%）**，缓发中子+冷却剂滞后 |
| 50 | 42.62 | 回落 |
| 100 | 40.43 | 收敛中 |
| **300** | **40.004** | **回归额定 ✓（+0.01%）** |

- 终态同工况A：440.04/550.05 ℃、ρ≈0（−7.1e-7）。
- **结论：无 PID 下 +10% 功率扰动自行回归 40 MW（峰值 +22%，持续时间约 10 s 量级，无发散）——系统具有固有（温度反馈）自稳能力。**

## 5. 结论与边界

1. **可以**——在额定平衡点邻域，无 PID 点堆能自稳于 40 MW，且扰动可自行恢复（负反馈：燃料/冷却剂温度）。
2. 恢复快慢由热惯性决定（~100–200 s 收敛到 ±0.1%）；瞬态峰值幅度由燃料反馈强度与冷却剂滞后决定。
3. **边界/局限性**：
   - 燃料反馈用的是**通道壁温**（棒体平均口径的代数近似，非燃料中心温度）——多普勒反馈的瞬时性偏理想；更真实需径向 2~3 节点管壁组件（见 PrimaryLoop 说明）。
   - **冷态（欠额定热态）无棒不能自稳**，启动需控制棒/PID（物理正确）。
   - 一回路边界（二回路 430 ℃ 恒流）固定；若排热能力持续下降（如 SFR_Stirling 的 t=1800 流量斜坡场景），自稳点会随排热特性移动——属后续工况，可另行验证。
4. 该机制解释了此前 SFR_Stirling 全系统在 PID CR≈0 时仍能 1000 s 稳在 40 MW：**负反馈回路本身在起主导作用，PID 只作为整定/启动辅助**。

## 6. 全系统验证（SFR_Stirling_Steady_noPID，同一套 PrimaryLoop_noPID 参数，300 s）

变体 `SFR.Structure.Closed.SFR_Stirling_Steady_noPID`（源布局原样）：constCR(k=0)→CR、燃料反馈接 T_wall[3] 份额加权（N=5 管）、Teffref_fuel=863.2/Teffref_coolant=768.29、功率分配改 0.2237/0.7763（源模型原为 19.09/80.9 旧口径）、活性段 h_start=609301（T[3]=768.29 K）、Q0_start=40e6。含二回路+斯特林（heff=1.41、d=10.6，同步 SecondLoop 标定）。

| t | Q [MW] | 说明 |
|---|---|---|
| 0 | 40.000 | 额定热态启动 |
| 10 | **49.93（峰值 +25%）** | 瞬态过冲（引擎回路动力学叠加） |
| 100 | 39.57 | 下冲 −1.1% |
| **300** | **40.169（+0.42%）** | **自稳 ✓** |

- ρ_总(300)=−8.5e-7≈0；ρ_fuel=−2.7e-7 / ρ_cool=−5.8e-7（Teff_fuel=872.75、Teff_coolant=768.293≈参考）
- 堆芯入口 **439.82 ℃**、出口 **550.28 ℃**、二回路出 HE1 **530.68 ℃**（设计 440/550.46/530）；引擎 **247.3 kW@1482 rpm**（目标 250/1500，−1.1%/−1.2%）
- **结论：PrimaryLoop_noPID 参数直接迁移到全系统同样成立**——无 PID 靠温度反馈自稳 40.17 MW（+0.42%，参考零点按一回路标定，全系统余差在 ±0.5% 内），过冲+25%（比一回路版 +22% 略大，二回路/引擎惯性所致），~200–300 s 收敛。
